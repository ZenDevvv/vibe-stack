# Truth Alignment

Classify findings before changing canonical documents:

- Accepted requirement evolution — update truth after confirmation.
- Documentation lag — synchronize stale documents.
- Implementation drift — repair code or revise accepted truth.
- Regression or quality drift — add verification and repair behavior.
- Terminology drift — reconcile vocabulary across truth, code, and UI.
- Unknown — preserve the uncertainty and ask for evidence.

When code reveals new durable truth, capture it in the appropriate truth document before closing the task.
